## ✦ Install

1. **[Download the APK](https://github.com/Xanfiend/tft-overlay/releases/latest/download/tft-scryer.apk)** on your Android phone.
2. Open it and allow **install from unknown sources** if asked.
3. If Play Protect warns about it, tap **Install anyway** (normal for apps outside the Play Store).
4. Open TFT Scryer → **Start Overlay** → launch TFT. Tap the floating sigil to use it.

> Android only — not for PC or iPhone.

## ✦ Is it safe?

Yes. The full source code is right here. No accounts, no ads, no tracking — everything stays on your phone, and the only network call is checking GitHub for updates. Antivirus warnings on self-signed APKs are a common false positive ([VirusTotal scan](https://www.virustotal.com/gui/file/effaa42fd316d6aa3a2948ee1b0370b176b2a6196d6da846e717dde3ae5f55f0/summary)).
